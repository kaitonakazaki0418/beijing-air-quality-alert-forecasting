# Beijing 24-Hour Air Quality Alert Forecasting

Predicting whether each of 12 Beijing monitoring stations will exceed AQI > 150 (Lightly Polluted) **24 hours ahead**, using only information available at prediction time. Built in R on 4 years of hourly multi-site sensor data (about 420k station-hours).

The project starts from a Persistence baseline and adds one idea at a time to an XGBoost classifier: neighbor-station AQI, lagged wind, K-means pollution-zone features, and airport weather. Each rung of this "model ladder" isolates the value of a single addition.

*Team project (3 students).*

## Key Results

Temporal split: train 2013-2015, tune thresholds on 2016, test on Jan-Feb 2017 (16k station-hours). AQI > 150 occurs in about 26% of test hours, so F1 is reported instead of accuracy.

| Lv | Model | F1 | AUC | Precision @ 90% Recall |
|---|---|---|---|---|
| 0 | Persistence (current alert status) | 0.555 | 0.765 | 0.350 |
| 1 | Logistic Regression | 0.548 | 0.770 | 0.381 |
| 2 | XGBoost | 0.568 | 0.767 | 0.411 |
| 3 | + Spatial (neighbor-station AQI) | 0.582 | 0.778 | 0.410 |
| 4 | + Wind & K-means cluster features | 0.566 | 0.779 | 0.417 |
| 5 | + ASOS airport weather | **0.588** | **0.790** | **0.420** |

- **Neighbor-station AQI gives the largest single gain** (Lv2 to Lv3, F1 +0.014).
- **The highest-gain feature in the strongest model is the K-means cluster-mean AQI**, which links the unsupervised zone analysis to predictive value.
- **Forecast horizon matters.** Persistence is unbeatable at 6 hours (AUC 0.91). By 24 hours the ladder is ahead by about 0.02 AUC, and by 72 hours Persistence falls to about 0.52 (essentially random) while the ladder holds near 0.57. A learned model starts to pay off around the 24-hour mark.
- **Cost-sensitive view.** Relative to Persistence, the ML models cut expected total cost by about 4% at equal miss and false-alarm costs, rising to about 17% when a missed alert costs 20 times a false alarm.

## Approach

- **No same-timestamp pollutants as inputs.** AQI is a deterministic function of pollutant concentrations (HJ 633-2012), so a model that sees current pollutants is re-deriving the formula, not forecasting. Only data available at prediction time is used.
- **Target:** AQI(t+24) > 150, computed per station.
- **Cleaning:** per-station gap filling (forward then backward fill), AQI computed with the piecewise-linear HJ 633-2012 formula, wind direction decomposed into U/V components. Rows missing any lag feature are dropped explicitly rather than letting NAs propagate silently.
- **Spatial analysis:** ANOVA confirms AQI differs by station and by season. K-means (k=3) on station pollutant profiles gives three zones: Industrial/Heavy (8 central stations), Mixed/Urban (2), and Residential/Green (2 peripheral).
- **Models:** XGBoost with early stopping on validation AUCPR (learning rate 0.05, max depth 4). Thresholds are tuned on the validation year only; the test period is untouched until final evaluation.
- **Evaluation:** F1 at the F1-optimal threshold, AUC, and Precision at 90% Recall (the operating point of an agency that wants to catch 90% of alerts), plus multi-horizon (6h, 24h, 48h, 72h) and cost-sensitive analyses (1:1 to 20:1 miss-to-false-alarm ratios).
- **A negative result:** an upwind-weighted neighbor AQI feature did not beat plain neighbor AQI.

## Limitations

- The test set covers only **Jan-Feb 2017** (the dataset ends in March 2017), so results describe winter performance. A full-year hold-out would be stronger.
- The 2016 validation year was less polluted than the training years, so threshold tuning happens on a partially out-of-distribution year.
- The ladder differences are small (F1 from 0.555 to 0.588), and results come from a single train/test split without confidence intervals. Lv4 is slightly below Lv3, which suggests partial redundancy between wind and neighbor features.
- The weather features come from **ASOS airport observations (Beijing Capital, ZBAA)**, not true ERA5 reanalysis, so boundary-layer height and similar variables are unavailable. (Some labels in the code and figures say "ERA5".)
- Station coordinates were curated by hand, and emission sources are not modeled.

## Repository Layout

```
R/                 source code
data/              raw UCI CSVs (read-only)
results/
  intermediate/    cleaned data, features, clusters
  final/           result tables
plots/             all figures
```

`results/` and `plots/` are regenerated by the pipeline; safe to delete.

## How to Run

**Requirements:** R 4.5+ and RStudio. An internet connection is needed for the airport weather download (`riem` package).

Open `DPA.Rproj` in RStudio, then in the console:

```r
source("R/data_pipeline.R")
```

The pipeline auto-installs missing packages and creates output folders on first run. It takes about 5-10 minutes end to end.

## R Scripts

| Script                   | Purpose                                                        |
|--------------------------|----------------------------------------------------------------|
| `data_pipeline.R`        | Orchestrator: sources all scripts in order                     |
| `clean_air_quality.R`    | Load 12 CSVs, gap-fill, compute AQI via HJ 633-2012            |
| `statistical_tests.R`    | ANOVA for station and season effects                           |
| `eda_plots.R`            | Trend line, heatmap, station comparison, correlation           |
| `time_series_analysis.R` | STL decomposition of daily mean AQI                            |
| `spatial_analysis.R`     | Station coordinates, spatial AQI map                           |
| `clustering_analysis.R`  | K-means (k=3), elbow plot, zone labeling, PCA visualization    |
| `feature_engineering.R`  | Lags, rolling means, wind U/V, neighbor pivot, cluster features|
| `model_ladder.R`         | Model ladder, threshold tuning, cost and horizon analysis      |

## Output Files

## Data

UCI Machine Learning Repository, Beijing Multi-Site Air Quality Data Set (12 stations, hourly, March 2013 to February 2017):
<https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data>

Airport weather: ASOS observations for Beijing Capital International Airport (ZBAA), downloaded with the `riem` R package.
